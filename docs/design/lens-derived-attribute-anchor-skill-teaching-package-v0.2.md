# LENS Derived Attribute Anchor Skill and Teaching Expression Package

Version: 0.2  
Status: High-Confidence Working Package for Continued Design and Playtesting  
Date: 2026-09-02

---

## Purpose

This package consolidates the current teaching architecture for Skills and
Derived Attribute routing:

```text
25 Derived Attributes
25 unique Anchor Skills
25 primary teaching Expressions
one or two accepted lateral routes for each Anchor Skill
selected extraordinary teaching Expressions
a companion larger illustrative Skill Index
Campaign Profile recommendations
player-proposed Skills
```

This version supersedes version 0.1 as the current Anchor roster and teaching
record. Version 0.1 remains useful design history and records the rapid first
pass that the deliberate review replaced.

This package does not independently change:

```text
the 25 / 50 / 75 construction spine;
Training Point or Rank progression;
Specialization cost or Rank progression;
HOLT purchase or Axis Rank procedures;
or the current Base Expression math.
```

The rules and examples in this package remain working material rather than
final published doctrine.

---

## Teaching Architecture

```text
The Anchor list teaches.

The Skill Index suggests.

The Campaign Profile guides.

The Character selects and develops.
```

An Anchor pairing answers:

```text
What familiar learned field most clearly demonstrates this Derived Attribute
in action?
```

It does not answer:

```text
Which Derived Attribute permanently owns this Skill?
```

During play, the routing question remains:

```text
What capability or established position is actually making this action
effective?
```

The Character remains the source. The applicable Attribute and Derived
Attribute identify the route through which the Character acts. The Skill
identifies the learned field being applied.

---

## Current Teaching Rules

### Anchor Pairings Are Not Ownership

An Anchor Skill is paired with the Derived Attribute that provides its
clearest primary teaching Expression. The pairing is not exclusive.

The same Skill may route through another Derived Attribute when the fiction
changes what is actually carrying the action.

### One Or Two Lateral Routes

Every Anchor Skill receives at least one clear lateral teaching route.

A second route is retained only when it adds genuine teaching value. Do not
force a second route for numerical or presentational symmetry.

Cross-Attribute routes are especially valuable because they demonstrate the
flexibility of LENS, but they are not mandatory. A same-Attribute route remains
valid when it demonstrates a genuinely different function.

### Same Skill, Different Function

A lateral Expression must preserve the same learned field. It cannot change
the Skill merely because another Skill could describe the same fictional
scene.

Each lateral route must answer:

```text
What changed in the fiction?

Why does this Derived Attribute now carry the action?

Does the same learned Skill remain active?

Does the example teach real flexibility without double-counting?
```

### Opposition Is Not A Lateral Route

A Lens that commonly opposes a Skill is not automatically a good lateral
teaching route for that Skill.

For example:

```text
Movement x Stealth
is commonly opposed by
Awareness x Observation.
```

Although Awareness could sometimes support a stealth attempt, using
`Awareness x Stealth` as the primary lateral example visually resembles the
opposing Expression and teaches the boundary poorly. The accepted Stealth
lateral therefore uses Manipulation instead.

### Skills Do Not Grant Extraordinary Permission

A Skill never creates an extraordinary capability merely because the Skill
could be applied to it.

```text
Healing does not grant regeneration.

Withstanding does not grant metal skin or invulnerability.

Survival does not grant abyssal adaptation.

Ranged Combat does not grant fire generation or energy projection.

Empathy does not grant telepathy.
```

Classification, Access, a HOLT, equipment, or another permission-bearing Lens
must supply the otherwise unavailable capability.

### Extraordinary Teaching Procedure

The extraordinary examples in this package use the following procedure:

```text
1. Keep the same Derived Attribute and Skill.

2. Add a HOLT that grants otherwise unavailable permission.

3. Apply the HOLT's ranked Axis through the relevant Derived Attribute.

4. Confirm that the Skill improves the application without granting the
   capability.

5. Confirm that the ordinary Expression still exists when HOLT Access is
   unavailable.
```

The HOLT names used below are illustrative. They do not create a universal
HOLT catalogue or require a setting to use those names.

Extraordinary includes magical, psychic, technological, mutational, divine,
artifactual, alien, and other setting-defined permissions.

## Might Anchor Skills

### Strength -> Lifting

**Skill definition:** Trained use of grip, posture, body mechanics, mechanical
advantage, and load handling to raise, support, carry, or reposition heavy
objects.

**Primary: `Might x Strength x Lifting`**  
Raise a heavy gate through direct physical force. Strength carries the action
because the central question is how much force the Character can exert against
the load.

**Lateral: `Mobility x Stability x Lifting`**  
Carry a tall, top-heavy statue across uneven ground without allowing the load
to shift, tip, or pull the Character off balance. The weight is manageable;
maintaining equilibrium carries the action.

**Lateral: `Psyche x Cognition x Lifting`**  
Determine where to place a fulcrum and how to sequence the effort so a stone
slab can be raised with limited available force. Solving the load problem
carries the action rather than direct force.

**Extraordinary teaching:** A Strength HOLT with a ranked Strength Axis permits
Lifting to catch, support, or raise a mountain-scale mass. A Gravity HOLT might
produce a superficially similar result by changing the mass relationship, but
that would not demonstrate extraordinary Strength.

### Toughness -> Withstanding

**Skill definition:** Practiced methods for enduring impact, pain, pressure,
or punishment while preserving function or intended purpose.

**Primary: `Might x Toughness x Withstanding`**  
Remain physically functional while receiving repeated blows or punishment.
Toughness carries the action because bodily durability under trauma is being
tested.

**Lateral: `Mobility x Stability x Withstanding`**  
Keep footing and position when struck by a charging opponent or driven by an
external force. Stability determines whether position is lost.

**Lateral: `Psyche x Resolve x Withstanding`**  
Preserve intention and refuse to capitulate under interrogation, coercion, or
torture. Resolve determines whether intention is broken.

**Extraordinary teaching:** A Metal Form HOLT with a ranked Toughness Axis
permits the Character to receive artillery-level impact without losing
function. Withstanding improves the practiced response; it does not create the
metal form or its durability.

Fortitude is a demonstration of successful Withstanding, not the learned
Skill. Physical fortitude may describe Toughness, mental or moral fortitude may
describe Resolve, sustained exertional fortitude may describe Vigor, and
environmental fortitude may describe Resistance.

### Resistance -> Survival

**Skill definition:** Trained practice for remaining alive and functional when
ordinary support is unavailable, including managing exposure, securing
necessities, recognizing hazards, and using the environment effectively.

**Primary: `Might x Resistance x Survival`**  
Manage exposure and remain functional while traveling through severe cold,
heat, altitude, or another physically hostile environment.

**Lateral: `Psyche x Awareness x Survival`**  
Notice changing weather, unstable terrain, contaminated water, animal signs,
or another environmental danger before it becomes immediate.

**Lateral: `Leverage x Background x Survival`**  
Use established cultural or formative knowledge to survive within a familiar
kind of terrain or environment.

**Extraordinary teaching:** An Aquatic HOLT with a ranked Resistance Axis may
permit Survival under abyssal pressure or another otherwise lethal marine
condition. Underwater breathing, if present, is an Access permission rather
than an automatic consequence of high Survival.

### Vigor -> Conditioning

**Skill definition:** Structured physical training and regulation used to
develop sustained output, pacing, and bodily readiness through repeated
exertion.

**Primary: `Might x Vigor x Conditioning`**  
Sustain demanding physical output through developed conditioning.

**Lateral: `Psyche x Awareness x Conditioning`**  
Monitor breathing, strain, hydration, and exertion so a prolonged effort can
be paced safely and effectively.

Resistance through acclimation, Resolve through adherence to a regimen, and
Stability through prolonged posture remain possible applications, but they do
not add enough teaching value to the core lateral set.

**Extraordinary teaching:** A cybernetic endurance HOLT with a ranked Vigor
Axis may permit continuous physical output for inhuman durations. Conditioning
governs how the Character manages and applies that capacity.

### Resilience -> Healing

**Skill definition:** Learned treatment and recovery practices used to restore
lost physical function or return health toward baseline.

**Primary: `Might x Resilience x Healing`**  
Support the Character's own return toward physical baseline through treatment,
rest, rehabilitation, and recovery practice.

**Lateral: `Psyche x Learning x Healing`**  
Recall and correctly apply an established treatment or recovery procedure.

**Lateral: `Psyche x Insight x Healing`**  
Diagnose what is wrong or identify what is preventing recovery.

**Extraordinary teaching:** A Regeneration HOLT with a ranked Resilience Axis
may permit rapid restoration of damaged tissue. Healing supplies practiced use
of the recovery capability; it does not grant regeneration.

When Healing is used upon another Character, Learning, Insight, Coordination,
equipment, Access, and the fiction may carry different parts of the treatment.
Resilience most directly carries the subject's own return toward baseline.

## Mobility Anchor Skills

### Movement -> Stealth

**Skill definition:** Learned avoidance of detection through concealment,
noise control, timing, route choice, and management of observer attention.

**Primary: `Mobility x Movement x Stealth`**  
Cross an observed area without attracting notice. Movement carries the action
because controlled physical relocation is the immediate objective.

**Lateral: `Influence x Manipulation x Stealth`**  
Create a timed distraction, misleading sound, or false trace that redirects an
observer's attention so the Character's actual action remains undetected.

The Manipulation route was selected over Awareness. `Awareness x Observation`
is the clean default active opposition to Stealth, and using
`Awareness x Stealth` as the principal lateral example teaches that opposition
poorly.

**Extraordinary teaching:** A Shadow HOLT with a ranked Movement Axis may
permit movement between available shadows while Stealth governs whether the
transition is detected.

### Maneuverability -> Acrobatics

**Skill definition:** Trained use of bodily rotation, redirection, aerial
orientation, vaulting, tumbling, and controlled movement through complicated
space.

**Primary: `Mobility x Maneuverability x Acrobatics`**  
Change bodily direction while vaulting through a confined or obstructed space.

**Lateral: `Influence x Presence x Acrobatics`**  
Make a dramatic entrance through an acrobatic display whose immediate personal
impression carries the action.

Movement, Stability, Coordination, Responsiveness, and Strength can all
naturally enter particular acrobatic Expressions. Presence is retained because
it provides the clearest lateral teaching without merely dividing the physical
technique into its expected components.

**Extraordinary teaching:** A Gravity HOLT with a ranked Maneuverability Axis
may permit the Character to reorient or change direction in midair without
ordinary physical support.

### Stability -> Balancing

**Skill definition:** Practiced maintenance and recovery of bodily equilibrium
upon narrow, unstable, moving, or otherwise disruptive support.

**Primary: `Mobility x Stability x Balancing`**  
Maintain footing on a narrow, unstable, or moving surface.

**Lateral: `Might x Resilience x Balancing`**  
Recover equilibrium after a physical effect has caused the Character to become
staggered or displaced. Stability prevents loss of equilibrium; Resilience
restores equilibrium that has already been lost.

**Extraordinary teaching:** A Gravity HOLT with a ranked Stability Axis may
permit a full-sized Character to remain perfectly balanced upon the head of a
pin. A violent wave alone is not a sufficient extraordinary teaching example,
because ordinary sea legs and exceptional Balancing could still explain it.

### Coordination -> Ranged Combat

**Skill definition:** Learned use of ranged attacks to acquire targets,
coordinate delivery, and place attacks at a distance.

**Primary: `Mobility x Coordination x Ranged Combat`**  
Aim and deliver a ranged weapon accurately.

**Lateral: `Mobility x Stability x Ranged Combat`**  
Maintain a firing platform while recoil, wind, unstable footing, or another
physical disruption presses against the shot.

**Lateral: `Influence x Projection x Ranged Combat`**  
Direct an emitted force, energy blast, or similar internally projected
capability toward a target when another Lens grants that capability.

Coordination places an attack. Projection transmits an internal capability.
They do not both contribute automatically merely because both descriptions are
available.

**Extraordinary teaching:** A Fire HOLT may grant the attack while its ranked
Coordination Axis improves precise placement. Projection may instead carry an
Expression primarily concerned with generating or transmitting the blast.

### Responsiveness -> Dodging

**Skill definition:** Practiced evasion through timely bodily adjustment to a
developing attack, collision, hazard, or other threat.

**Primary: `Mobility x Responsiveness x Dodging`**  
Reactively evade an attack after its approach becomes apparent.

**Lateral: `Psyche x Awareness x Dodging`**  
See or otherwise detect the developing threat early enough to begin the
evasion.

**Lateral: `Psyche x Insight x Dodging`**  
Anticipate the attack from an opponent's pattern, intention, or setup and avoid
being where the attack is going.

**Extraordinary teaching:** A Precognition HOLT with a ranked Responsiveness
Axis may permit the Character to begin evading before ordinary sensory warning
makes that response possible.

Vehicle Operation remains another strong Skill application for Responsiveness
when reacting through a vehicle's controls. It is not a lateral route for the
Dodging Skill.

## Psyche Anchor Skills

### Cognition -> Planning

**Skill definition:** Learned organization of objectives, resources,
constraints, sequence, and anticipated developments into a usable course of
action.

**Primary: `Psyche x Cognition x Planning`**  
Construct a coordinated plan from known objectives, resources, and
constraints.

**Lateral: `Leverage x Assets x Planning`**  
Create and allocate a practical budget, supply plan, or quartermaster schedule
from the resources the Character actually controls.

**Lateral: `Influence x Manipulation x Planning`**  
Arrange incentives, timing, information, and pressure so another party is
likely to make the intended decision.

**Extraordinary teaching:** A Machine Mind HOLT with a ranked Cognition Axis may
permit the Character to model thousands of interacting variables and construct
a viable plan within moments.

### Learning -> Research

**Skill definition:** Systematic location, comparison, evaluation, and
assembly of information from available sources to answer a question or develop
understanding.

**Primary: `Psyche x Learning x Research`**  
Locate, evaluate, and assemble information from available records, testimony,
databases, or other sources.

**Lateral: `Leverage x Background x Research`**  
Investigate ancestry, roots, cultural significance, formative events, or
historical associations through established context and access supplied by the
Character's Background.

Studying remains a separate possible Skill Index entry. Research discovers,
locates, evaluates, and assembles information; studying repeatedly examines or
practices known material so it can be internalized.

**Extraordinary teaching:** A Psychometry HOLT with a ranked Learning Axis may
permit the Character to research an object's history through impressions
otherwise inaccessible within it.

### Awareness -> Observation

**Skill definition:** Practiced directed attention to present sensory or
otherwise available information so relevant details and changes are noticed.

**Primary: `Psyche x Awareness x Observation`**  
Deliberately watch an area and notice relevant activity.

**Lateral: `Leverage x Network x Observation`**  
Use reports, rumors, and distributed attention across established contacts to
observe a community's current street pulse.

Search may appear in the larger Skill Index when a Campaign Profile needs a
distinct learned practice for actively locating concealed subjects.
Observation remains present reception and attention rather than systematic
information retrieval.

**Extraordinary teaching:** A Clairvoyance HOLT with a ranked Awareness Axis
may permit observation of events occurring at a distant location without
physical presence.

### Insight -> Inference

**Skill definition:** Practiced derivation of plausible unstated conclusions
from evidence, patterns, relationships, and context.

**Primary: `Psyche x Insight x Inference`**  
Derive an unstated conclusion from available evidence and context.

**Lateral: `Leverage x Background x Inference`**  
Interpret an ambiguous custom, symbol, statement, or event through established
cultural or formative context.

Inference is distinct from Deduction. Deduction derives a conclusion that is
logically required by its premises. Inference identifies a plausible unstated
conclusion from incomplete evidence, patterns, and context. Recognition is the
mental event; Inference is the learned practice.

**Extraordinary teaching:** A Precognition HOLT with a ranked Insight Axis may
permit the Character to interpret fragmentary future impressions and identify
the most likely developing outcome.

### Resolve -> Concentration

**Skill definition:** Practiced maintenance of deliberate attention and mental
direction despite distraction, discomfort, pressure, or competing demands.

**Primary: `Psyche x Resolve x Concentration`**  
Maintain deliberate attention despite distraction, discomfort, or pressure.

**Lateral: `Psyche x Awareness x Concentration`**  
Sustain attention upon a faint signal or subtle detail despite competing
sensory information.

**Lateral: `Mobility x Coordination x Concentration`**  
Perform a prolonged, delicate physical task without allowing attention or
movement to drift.

Toughness under pain is taught more cleanly through Withstanding. Stability
while aiming is taught more cleanly through Ranged Combat and Balancing.

**Extraordinary teaching:** A Psychic HOLT with a ranked Resolve Axis may
permit the Character to sustain a psychic barrier or projected mental
construct under severe interference or attack.

## Influence Anchor Skills

### Presence -> Presentation

**Skill definition:** Practiced shaping of immediate outward impression through
appearance, demeanor, posture, timing, and visible or audible conduct.

**Primary: `Influence x Presence x Presentation`**  
Deliberately shape how the Character immediately registers before transmitting
a specific message or attempting a specific change.

**Lateral: `Influence x Projection x Presentation`**  
Deliver organized information, an argument, a proposal, an image, or another
prepared conception effectively to an audience.

Presence and Presentation passed the independence test:

```text
High Presence and high Presentation
Compelling and polished.

High Presence and low Presentation
Compelling but uncontrolled or poorly shaped.

Low Presence and high Presentation
Polished but personally unremarkable.

Low Presence and low Presentation
Neither strongly registering nor deliberately shaped.
```

Presentation must remain limited enough that it does not replace Oratory,
Persuasion, Intimidation, Leadership, Deception, or other learned social
fields.

**Extraordinary teaching:** A Transformation HOLT with a ranked Presence Axis
may permit the Character to reveal or compose an extraordinary form so it
immediately registers as awe-inspiring, terrifying, beautiful, unsettling, or
overwhelming.

Presence does not establish recognized office, legitimacy, or jurisdiction.
Those functions belong to Authority. Do not define Presence as authoritative.

### Projection -> Oratory

**Skill definition:** Practiced composition and delivery of organized spoken
content to an audience.

**Primary: `Influence x Projection x Oratory`**  
Deliver an organized speech so its intended message reaches and is understood
by the audience.

**Lateral: `Influence x Presence x Oratory`**  
Hold the audience's attention through the speaker's immediate personal force,
independent of the speech's particular argument or message.

**Lateral: `Psyche x Cognition x Oratory`**  
Compose and structure a coherent speech. Speechwriting is the job or
application; Oratory remains the broader learned Skill.

Projection governs deliberate outward transmission. It does not determine
whether the audience agrees, obeys, forms a relationship, or changes state.

**Extraordinary teaching:** A Telepathy HOLT with a ranked Projection Axis may
permit the Character to deliver an oration directly into receptive minds
across a vast area.

Other established Projection applications include:

```text
Projection x Performance
Transmit emotional, aesthetic, symbolic, or dramatic content.

Projection x Illusion
Manifest sensory content or an outward false appearance when permission
exists.

Projection x Ranged Combat
Transmit an offensive capability toward a target when permission exists.

Projection x Language
Communicate a deliberate message through a trained language.
```

### Connection -> Empathy

**Skill definition:** Practiced response to another person's emotions,
experiences, or perspective in a way that makes the person feel recognized,
understood, or supported.

**Primary: `Influence x Connection x Empathy`**  
Establish or sustain trust by responding meaningfully to another person's
emotional experience.

Natural empathy may exist without training. Empathy as a Skill represents its
developed, reliable application.

**Lateral: `Psyche x Insight x Empathy`**  
Understand the unspoken emotional need, fear, or perspective beneath what
someone is saying.

**Lateral: `Influence x Manipulation x Empathy`**  
Calm a panicked or distressed person by responding in a way that changes the
person's emotional state.

Awareness may notice emotional cues, but Observation already teaches that
reception cleanly. Insight and Manipulation provide the stronger retained
routes.

**Extraordinary teaching:** A Psychic HOLT with a ranked Connection Axis may
permit a direct empathic bond through which emotions can be experienced or
shared.

### Manipulation -> Deception

**Skill definition:** Learned creation, presentation, and maintenance of false
or misleading information, identity, appearance, or implication.

**Primary: `Influence x Manipulation x Deception`**  
Cause another person to adopt a mistaken belief through falsehood,
concealment, misdirection, or misleading presentation.

**Lateral: `Influence x Projection x Deception`**  
Deliver a prepared false account clearly and convincingly.

**Lateral: `Psyche x Cognition x Deception`**  
Construct a false account that remains internally consistent under review.

Deception and Persuasion remain separate Skills:

```text
Deception
Creates or maintains a mistaken belief through falsehood, concealment, or
misdirection.

Persuasion
Changes an attitude or decision through reasons, appeals, incentives, or
values presented for consideration.
```

Argumentation is a likely Persuasion Specialization for changing a position
through structured evidence and logical reasoning. Proof is the evidence or
reasoning that establishes a conclusion, not necessarily the Skill used to
present it.

**Extraordinary teaching:** An Illusion HOLT with a ranked Manipulation Axis
may permit the Character to cause a target to accept a projected sensory
fabrication as genuine. Projection may manifest the sensory content;
Manipulation changes the target's belief about it.

### Control -> Command

**Skill definition:** Learned direction and coordination of participants who
are willing, assigned, subordinate, or otherwise available to be directed.

**Primary: `Influence x Control x Command`**  
Direct and coordinate available participants in carrying out an intended
course of action.

**Lateral: `Influence x Projection x Command`**  
Issue an order clearly enough to be understood through noise and confusion.

**Lateral: `Leverage x Authority x Command`**  
Direct an official response through an established office and recognized
chain of command.

Projection gets the order across. Authority supplies recognized right or
jurisdiction. Control directs and regulates the resulting coordinated action.
Command does not create obedience, loyalty, office, or Access where none
exists.

**Extraordinary teaching:** A Beast HOLT with a ranked Control Axis may permit
the Character to direct animals or creatures that ordinary communication and
authority could not command.

## Leverage Anchor Skills

### Assets -> Trading

**Skill definition:** Learned exchange and commitment of controlled money,
property, goods, holdings, or other material resources to obtain value.

**Primary: `Leverage x Assets x Trading`**  
Exchange or commit controlled resources to obtain goods, services, access,
cooperation, or another available advantage.

**Lateral: `Psyche x Insight x Trading`**  
Appraise an offered item's practical value, significance, or hidden weakness
within an exchange. Appraisal is the application; Trading remains the broader
Skill.

**Lateral: `Influence x Manipulation x Trading`**  
Change the other party's position during a negotiated exchange.

Trading does not make unavailable goods available or create legal Access.

**Extraordinary teaching:** A Sorcery HOLT with a ranked Assets Axis may permit
the Character to bargain with memories, years of life, dreams, or other things
that cannot ordinarily function as exchangeable Assets.

### Network -> Solicitation

**Skill definition:** Learned requesting of aid, participation, information,
resources, or support from people or organizations available to be asked.

**Primary: `Leverage x Network x Solicitation`**  
Ask established contacts to contribute information, transportation, resources,
introductions, or participation to a current objective.

**Lateral: `Leverage x Reputation x Solicitation`**  
Request support because established public standing makes people willing to
answer.

**Lateral: `Influence x Connection x Solicitation`**  
Make a request through rapport established during the present interaction.

Solicitation asks an available relationship to contribute. Persuasion becomes
the stronger Skill when a reluctant party's present position must be changed.

**Extraordinary teaching:** A Spirit HOLT with a ranked Network Axis may permit
the Character to request information or assistance from spirits with whom the
Character has established relationships. The HOLT permits such relationships;
Network determines which relationships actually exist.

### Authority -> Enforcement

**Skill definition:** Learned application of an established rule, order,
judgment, restriction, or official decision through recognized procedure.

**Primary: `Leverage x Authority x Enforcement`**  
Apply an established law, warrant, order, restriction, or official decision
through recognized jurisdiction.

**Lateral: `Influence x Control x Enforcement`**  
Direct and regulate behavior after a valid restriction, order, or procedure
has been established.

**Lateral: `Psyche x Awareness x Enforcement`**  
Inspect a regulated location, process, or activity for observable violations
using learned enforcement procedure.

Strength was rejected as a core lateral. Physically moving a barricade or
restraining someone normally uses Lifting, Unarmed Combat, or another physical
Skill unless learned enforcement procedure remains a distinct contribution.

Enforcement does not create office, jurisdiction, a warrant, or current Access.

**Extraordinary teaching:** A Divine Mandate HOLT with a ranked Authority Axis
may permit enforcement of a sacred prohibition against a being subject to the
Character's recognized cosmic jurisdiction.

### Reputation -> Endorsement

**Skill definition:** Deliberate placement of established public standing
behind a person, claim, cause, product, organization, or request so that the
association carries credibility, legitimacy, attention, confidence, fear, or
other consequence.

**Primary: `Leverage x Reputation x Endorsement`**  
Publicly place the Character's trusted or notorious standing behind another
person's disputed claim or cause.

**Lateral: `Influence x Projection x Endorsement`**  
Deliver the endorsement clearly to its intended audience.

**Lateral: `Leverage x Network x Endorsement`**  
Place relational standing behind someone within an established organization
or community.

Recognition that produces an automatic response does not require an active
Endorsement Expression. Solicitation remains the Skill when the Character asks
for favorable treatment rather than placing standing behind another subject.

**Extraordinary teaching:** A Living Legend HOLT with a ranked Reputation Axis
may permit a mythically recognized identity to carry significance among beings,
traditions, artifacts, or communities that participate in that legend.

This is a boundary case. Worldwide or interplanetary fame may require only high
Reputation and appropriate Scale. The HOLT is justified only when the legend
itself creates an otherwise unavailable kind of recognition or permission.

### Background -> Language

**Skill definition:** Learned comprehension and production of meaningful
spoken, signed, written, encoded, or otherwise structured communication.

**Primary: `Leverage x Background x Language`**  
Use a language through established culture, upbringing, or formative history.

**Lateral: `Psyche x Learning x Language`**  
Use or translate a language acquired through deliberate study.

**Lateral: `Psyche x Insight x Language`**  
Infer the meaning of an unfamiliar phrase, idiom, inscription, or language
puzzle through context and internal relationships.

Projection can carry the clear delivery of a deliberate message through
Language, but Learning and Insight provide the stronger retained teaching
routes.

The fiction must establish a basis for the particular language. A Language
Rank does not make every unknown language applicable.

**Extraordinary teaching:** An Ancestral Memory HOLT with a ranked Background
Axis may permit the Character to speak or interpret a forgotten ancestral
language through inherited memory rather than personal study.

## Supplemental Accepted Examples

These examples were useful during the review but do not replace the twenty-five
Anchor pairings.

### Toughness And Intimidation

```text
Might x Toughness x Intimidation
```

The Character withstands a blow or breaks a bottle over their own head as a
demonstration intended to establish dominance. Toughness carries the physical
demonstration; Intimidation remains the learned coercive practice.

### Stuntwork

Stuntwork remains a useful Skill Index candidate rather than the Toughness
Anchor. It may route through Toughness when safely receiving impacts, Movement
or Maneuverability when performing the stunt, Awareness when reading hazards,
Resolve when acting through fear, or Reputation when established professional
standing carries the action.

### Performance

Performance remains a useful Skill Index candidate. Projection transmits the
content of a performance, Presence holds attention through the performer, and
Coordination executes demanding physical or instrumental technique.

### Illusion

Illusion remains a permission-sensitive Skill Index candidate or application.
Projection may manifest sensory content, Manipulation may cause a target to
accept that content as genuine, and Control may direct or maintain an existing
illusion. Illusion alone does not grant extraordinary manifestation.

### Vehicle Operation

Vehicle Operation remains a useful Skill Index and Campaign Profile candidate.
Responsiveness handles sudden hazards through the controls, Maneuverability
changes course and orientation, Cognition handles complex procedures, and the
vehicle's own Scale and characteristics remain separate Lenses.
