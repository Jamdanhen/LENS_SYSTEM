# LENS Leverage Derived Attribute Boundary Test

Version: 0.1  
Status: Working Boundary Test; No New Doctrine Adopted  
Date: 2026-08-31

> Terminology update, 2026-09-01: `Background` replaces `Heritage` as the
> current fifth Leverage Derived Attribute name. Heritage references below are
> preserved as the language under which this test was originally run. The
> tested mechanical function now routes through Background.

---

## Purpose

This test follows the Leverage fifth-Attribute architecture test.

It holds one Character and one objective constant while changing the fictional
source used to pursue that objective.

The test determines when each candidate:

```text
carries the Expression;
creates only Access;
provides no relevant contribution;
and creates a distinct target for counterplay.
```

Candidate Leverage Derived Attributes:

```text
Assets
Network
Authority
Reputation
Heritage
```

Influence is included as the control.

---

## Scenario

```text
A noble attempts to secure soldiers and supplies from a local ruler so a
nearby settlement can be defended.
```

The desired outcome remains the same in every test.

The Character may pursue that outcome by:

```text
offering material support;
calling upon an established relationship;
issuing a valid command;
invoking established reputation;
invoking a historical or inherited obligation;
or personally persuading the ruler.
```

Each route is tested separately. The routes are not stacked.

## Test 1: Assets Carries the Expression

Declaration:

```text
I will pay the cost of deploying the ruler's soldiers and replace the supplies
consumed while defending the settlement.
```

Narrative function:

```text
The Character's established material position is the reason the ruler can and
will provide aid.
```

Carrying route:

```text
Leverage / Assets / Persuasion
```

The Persuasion Skill represents negotiating the offer. Assets supplies the
material force carrying it.

Assets provides only Access when:

```text
the Character pays an entrance fee or supplies a gift only to obtain an
audience, after which a different Expression must persuade the ruler.
```

Assets provides no relevant contribution when:

```text
the ruler cannot be bought;
the offered resources do not address the actual obstacle;
the Character cannot access the promised resources;
or the declared action relies entirely on another source of force.
```

Distinct counterplay:

```text
Assets Frozen
Credit Refused
Supply Route Severed
Ownership Contested
Offer Politically Unacceptable
```

Finding:

```text
PASS

Assets measures established material means brought to bear. It does not
measure the technical function of an item or the Character's personal charm.
```

## Test 2: Network Carries the Expression

Declaration:

```text
The ruler and I defended the northern pass together. I call upon that trust and
our standing promise of mutual aid.
```

Narrative function:

```text
The established relationship itself creates the obligation or willingness to
help.
```

Carrying route:

```text
Leverage / Network / Persuasion
```

Network provides only Access when:

```text
a mutual contact introduces the Character to the ruler but does not influence
the ruler's final decision.
```

Network provides no relevant contribution when:

```text
the relationship is too remote;
the contact has no influence over this decision;
the relationship does not include the requested kind of aid;
or the Character is merely name-dropping someone irrelevant.
```

Distinct counterplay:

```text
Trust Broken
Ally Compromised
Favor Already Spent
Relationship Severed
Conflicting Loyalty
```

Finding:

```text
PASS

Network measures established relational support. It remains distinct from
Authority because a friend may help without being subject to command.
```

## Test 3: Authority Carries the Expression

Declaration:

```text
Under the emergency charter, I order the ruler to provide the levy assigned to
this district.
```

Narrative function:

```text
The Character possesses a recognized right to direct this decision.
```

Carrying route:

```text
Leverage / Authority / Command
```

Authority provides only Access when:

```text
the Character's title guarantees an audience, ceremonial precedence, or entry
to the court but grants no jurisdiction over the ruler's troops.
```

Authority provides no relevant contribution when:

```text
the ruler is legally independent;
the Character acts outside the office's jurisdiction;
the commission has expired;
the requested act exceeds the delegated power;
or the title is unrecognized.
```

Distinct counterplay:

```text
Office Revoked
Jurisdiction Disputed
Commission Expired
Order Unlawful
Legitimacy Contested
```

Finding:

```text
PASS

Authority measures an established right to direct, decide, or compel. It does
not mean that every high-status person may command every lower-status person.
```

---

## Test 4: Reputation Carries the Expression

Declaration:

```text
The ruler knows I held the river crossing when every other commander withdrew.
My warning that the settlement will fall carries established credibility.
```

Narrative function:

```text
Shared belief about the Character changes how the request is received.
```

Carrying route:

```text
Leverage / Reputation / Persuasion
```

Reputation may be favorable or unfavorable. Trust, fear, honor, notoriety, or
public expectation can carry an Expression when that exact belief matters.

Reputation provides only Access when:

```text
recognition gets the Character admitted, noticed, or heard but does not affect
the ruler's decision once the discussion begins.
```

Reputation provides no relevant contribution when:

```text
the ruler has never heard of the Character;
the reputation concerns an unrelated field;
the ruler rejects the public account;
or anonymity prevents recognition.
```

Distinct counterplay:

```text
Publicly Disgraced
Credibility Undermined
False Report Circulated
Identity Concealed
Reputation Irrelevant Here
```

Finding:

```text
PASS

Reputation measures established external belief. It remains distinct from
Influence because the force existed before the current conversation.
```

## Test 5: Heritage Carries the Expression

Declaration:

```text
Our houses signed the Stonewater Compact. When either border settlement is
threatened, both lines are bound to answer.
```

Narrative function:

```text
An established historical, cultural, familial, or inherited relationship
creates a recognized claim or obligation.
```

Carrying route:

```text
Leverage / Heritage / Persuasion
```

Heritage provides only Access when:

```text
ancestry, culture, or historical belonging grants an audience, hospitality,
recognition, or permission to invoke the relevant custom, but the custom does
not itself require aid.
```

Heritage provides no relevant contribution when:

```text
the claimed tradition is unknown or rejected;
the historical relationship contains no applicable obligation;
the Character merely knows history rather than possessing a relationship to
it;
or the claim belongs to Reputation, Authority, or Network instead.
```

Distinct counterplay:

```text
Lineage Contested
Treaty Renounced
Exile
Claim Superseded
Cultural Standing Denied
```

Finding:

```text
PASS WITH TERMINOLOGY CAUTION

The mechanical function is distinct: established historical belonging and
claims brought to bear.

`Heritage` works for the tested cases but remains the candidate most likely to
need a broader final name if personal history, adopted culture, and noninherited
legacy must all fit naturally.
```

## Test 6: Influence Carries the Expression

Declaration:

```text
Forget my title and my house. If the settlement falls, the eastern road is
open and your own people are next. Send the soldiers because it is the right
decision.
```

Narrative function:

```text
The Character's current argument and personal ability to change the ruler's
decision carry the Expression.
```

Carrying route:

```text
Influence / Manipulation / Persuasion
```

The Character does not need Assets, Network, Authority, Reputation, Heritage,
or a noble HOLT to attempt this route.

House Valerin may have created Access to the court. That does not cause the
HOLT to multiply the persuasion unless an applicable House Valerin Axis
actually contributes to the declared Expression.

Distinct counterplay:

```text
Communication Prevented
Argument Discredited
Ruler Unwilling to Listen
Mental or Social Dissonance
Opposing Persuasion
```

Finding:

```text
PASS

Influence remains the route for direct outward change. Leverage is not a
replacement for ordinary social action.
```

## Test 7: Same Outcome, Different Expressions

All six routes can seek the same result:

```text
The ruler sends soldiers and supplies.
```

They do not establish the same fictional result around that outcome:

```text
ASSETS
The ruler is compensated or materially enabled.

NETWORK
The ruler answers a relationship or reciprocal obligation.

AUTHORITY
The ruler complies with a recognized command.

REPUTATION
The ruler trusts, fears, or responds to established public belief.

HERITAGE
The ruler honors a historical, cultural, familial, or inherited claim.

INFLUENCE
The ruler is persuaded by the current communication.
```

Those differences matter after success:

```text
Assets may create debt, expenditure, or contractual expectations.

Network may spend a favor or strain a relationship.

Authority may create accountability, resistance, or legal consequences.

Reputation may raise expectations or attract scrutiny.

Heritage may reaffirm or expose an inherited obligation.

Influence may change the ruler's current decision without establishing any
durable worldly relationship.
```

Finding:

```text
STRONG PASS

The Derived Attributes do not merely rename six ways to roll Persuasion. Each
route identifies a different truth carrying force, a different consequence,
and a different target for counterplay.
```

## Test 8: Access-Only Control

The following statements create Access but do not automatically enhance the
final request:

```text
Assets pays the court fee.

Network supplies an introduction.

Authority grants entry to the council chamber.

Reputation causes the guards to recognize the Character.

Heritage grants the right to petition the ruler.
```

After Access is established, the Character still needs an Expression capable
of securing the aid.

If the same truth does more than open the door, the player must state how it
actually carries force in the declared objective.

Finding:

```text
PASS

The architecture preserves the distinction between permission and numerical
effect.

Access does not automatically become a multiplier.
```

## Test 9: No Attribute Shopping

Rejected constructions:

```text
Use Influence / Assets because the outcome is social.

Use Leverage / Reputation for personal charm when nobody knows the Character.

Use Leverage / Authority because the Character speaks confidently.

Use Leverage / Heritage because the Character studied history.

Use Influence and Leverage together because both could help.
```

Correct rule:

```text
Identify the single broad locus carrying the declared Expression.

Then identify the applicable Derived Attribute, Skill, Specialization, HOLT
Axis, Access, Scale, Difficulty, Resonance, Dissonance, and opposition.
```

Another truth may establish Access or another distinct function. It does not
automatically add a second Attribute to the same Expression.

Finding:

```text
PASS

The derivative locus inheritance rule and the existing applicability rule are
sufficient. No Leverage-specific exception is required.
```

## Test 10: HOLT Partial Loss

House Valerin suffers the following conditions:

```text
Royal Charter Revoked
House Accounts Frozen
Lineage Contested
```

Possible Access results:

```text
House Valerin / Authority Axis:  Closed
House Valerin / Assets Axis:     Condition or Closed
House Valerin / Heritage Axis:   Condition
House Valerin / Network Axis:    Open unless a relationship is separately lost
House Valerin / Reputation Axis: Open, although its fictional meaning may have
                                 changed
```

The HOLT remains part of the Character. Its Axes do not all disappear merely
because one relationship is attacked.

The Character may still use ordinary Leverage routes supported independently
of House Valerin, subject to the relevant facts and Conditions.

Finding:

```text
PASS

The five Derived Attributes create clean partial counterplay. A HOLT can be
damaged, narrowed, or transformed without being treated as one indivisible
background package.
```

## Boundary Findings

```text
Assets
Material means committed to the objective.

Network
Established relationship or affiliation answering the objective.

Authority
Recognized right to direct, decide, or compel the objective.

Reputation
Established external belief changing the objective's reception.

Heritage
Established historical, cultural, familial, or inherited relationship
supporting a claim, obligation, or belonging.

Influence
Current personal projection changing an external attitude, belief, emotion,
decision, or state.
```

Short diagnostic questions:

```text
What controlled means are being committed?                 Assets

What established relationship is answering?                Network

What recognized right permits direction or decision?       Authority

What prior belief about the Character matters?              Reputation

What historical belonging or claim matters?                 Heritage

What is the Character doing right now to change the target? Influence
```

---

## Overall Finding

```text
STRONG PASS

Assets, Network, Authority, Reputation, and Heritage survive direct boundary
testing against one another and against Influence.

Each can carry the same desired outcome through a different fictional source.

Each can create only Access when it opens an opportunity without carrying the
declared objective.

Each can be irrelevant when its established truth does not answer the current
action.

Each creates distinct counterplay, Conditions, consequences, and recovery.

The HOLT Axis rule remains unchanged.

The parent Attribute rule remains unchanged.

No separate Background resolution system is required.
```

---

## Remaining Pressure Point

The architecture passed. The only significant terminology pressure remains:

```text
Does Heritage naturally cover all established historical identity, including
adopted culture, exile, personal history, and noninherited legacy?
```

The function itself survived. The word may need a later comparison against
`Origin`, `Legacy`, `Belonging`, or another candidate.
