# LENS Training Pool 75 vs. 100 Test v0.1

Date: 2026-09-03

Status:

```text
EXPERIMENTAL TEST RECORD
NO TRAINING BUDGET CHANGED BY THIS TEST
TASK, PARENT, AND BRANCH REMAIN WORKING TERMS
```

## Purpose

Compare the current 75-point shared Training pool with the proposed 100-point
pool after the candidate Training architecture expanded to:

```text
Task
x applicable portable Parent Specialization
x applicable parent-bound Branch
```

The candidate construction progression is:

```text
25 Attribute Points
50 Derived Attribute Points
100 Training Points
```

This may be expressed as:

```text
Attribute pool x1 = 25
Derived Attribute pool x2 = 50
Training pool x2 again = 100
```

The additional 25 points are therefore not tested as an isolated balance
grant. They are tested as a possible consequence of doubling the allocation
at each deeper construction order.

The exact Task catalogue remains unresolved. This test uses unnamed Task
slots so it does not silently adopt the former Anchor Skill list as the final
Task list.

## Inherited Controls

```text
One Training Point purchases one Rank.

Rank 0  = x1.0
Rank 1  = x1.1
...
Rank 10 = x2.0

Unranked ordinary Tasks remain possible through the applicable Attribute or
Derived Attribute.

Parent and Branch contribute only when applicable.

Branch Rank may exceed Parent Rank.

The default working hierarchy stops at Branch.
```

No HOLD, HOLT, Axis, equipment, active Resonance, Dissonance, Scale change, or
additional Campaign Profile depth is included.

## Task-Count Sensitivity

If every Training Point were spent only upon Tasks, the even-distribution
diagnostic would be:

| Identified Tasks | 75-point average | 100-point average |
|---:|---:|---:|
| 25 | Rank 3.00 | Rank 4.00 |
| 30 | Rank 2.50 | Rank 3.33 |
| 40 | Rank 1.875 | Rank 2.50 |
| 50 | Rank 1.50 | Rank 2.00 |

These are not required distributions. They demonstrate why the eventual Task
count or Task-grouping architecture directly affects the meaning of either
budget.

The 100-point pool does not eliminate this dependency. It gives one
additional Rank per Task if the teaching control remains twenty-five Tasks.

## What the Additional 25 Points Purchase

Begin with the 75-point generalist control:

```text
25 Tasks at Rank 3
```

Moving to 100 provides exactly twenty-five additional Training Ranks. Those
points could produce very different Characters:

```text
Breadth
Raise all twenty-five Tasks from Rank 3 to Rank 4.

Several focused routes
Purchase five Parents at Rank 3 and five subordinate Branches at Rank 2.

Extreme depth
Purchase one Parent and one Branch at Rank 10, with five Ranks remaining for
another development choice.

Mixed construction
Distribute the additional Ranks among Tasks, Parents, and Branches according
to the Character's actual practice and identity.
```

This is the strongest structural argument for 100 points. The additional
twenty-five can function as a character-defining depth budget while preserving
the former 75-point Task baseline. No formal reservation or separate pool is
required; the points remain freely shared.

## Findings

```text
PASS:
Both 75 and 100 produce mathematically distinct generalists, professionals,
and narrow specialists.

PASS:
The 100-point pool follows a coherent 25 / 50 / 100 construction progression.

PASS:
The additional twenty-five points can purchase breadth, several moderate
focused routes, or one extreme route without creating another currency.

PASS:
Applicability and fallback continue to distinguish broad from narrow
development.

CAUTION:
The 100-point pool is not merely corrective. It materially raises professional
and narrow signature Expressions.

UNRESOLVED:
The adequacy of either pool cannot be finalized until the Task catalogue or
Task-grouping architecture shows how many recurring activities Characters are
actually expected to develop.
```

## Assessment

The 75-point pool is functional. It is not mathematically broken. Its cost is
that substantial Parent and Branch development must replace a noticeable
amount of Task breadth.

The 100-point pool better supports the newly proposed three-depth Training
architecture. It allows the previous 75-point breadth chassis to survive while
providing one additional twenty-five-point quantum for character-defining
development.

The current leading test recommendation is therefore:

```text
Retain 100 Training Points as the active candidate for the next complete
character-construction test.

Do not adopt it as final until the Task catalogue or Task-grouping analysis is
complete.
```

## Exact Next Dependency

```text
Identify the intended Task landscape:

- approximately how many broadly reusable Tasks the system needs to teach;
- which Tasks are true recurring activities rather than subjects, outcomes,
  permissions, or Derived Attribute uses;
- whether the useful structure is a list, a set of Task groupings, or both;
- and how many ranked Tasks an ordinary Character is expected to possess.
```
