# LENS Anchor Skill Boundary Stress Test

Version: 0.1  
Status: Working Architecture Test; No Skill Adoption  
Date: 2026-09-01

---

## Purpose

Stress-test the closest boundaries in the proposed twenty-five Anchor Skill
teaching architecture before that architecture replaces any current Skill
presentation.

The test concentrates on five candidate boundaries:

```text
Conditioning / Athletics / Rehabilitation / Medicine / Meditation
Solicitation / Persuasion
Endorsement / automatic Reputation
Enforcement / Command
Arts / artistic Specializations
```

The test does not ask whether all five candidate names are attractive. It asks
whether each proposed Skill performs a recurring learned function that remains
distinct when the same fictional situation is routed through different Lenses.

---

## Governing Controls

### The Skill Must Remain the Learned Field

Changing the Derived Attribute changes what is making the action effective.
It does not silently change the Skill being used.

### A Lens Must Make a Distinct Contribution

Two Skills or Lenses do not both contribute merely because their names are
related. Each must perform separate work in the declared Expression.

### Permission Remains Separate

A Skill does not create:

```text
equipment;
recognized Authority;
an existing Network;
public Reputation;
Access to a target or institution;
extraordinary bodily recovery;
or another higher-order permission.
```

### No Roll Is Required When Nothing Meaningful Is Uncertain

A stable Lens may establish an automatic response, Access, or contextual
Resonance without requiring an active Skill Expression.

## Test One: Physical Preparation, Exertion, and Recovery

### Candidate Boundaries

```text
Conditioning
Structured bodily preparation and maintenance.

Athletics
Practiced performance of demanding bodily movement and exertion.

Rehabilitation
Planned restoration of lost bodily function after disruption.

Medicine
Learned assessment and treatment of injury, illness, or bodily dysfunction.

Meditation
Trained internal self-regulation through attention, breathing, relaxation,
and related practices.
```

### Scenario A: Preparing for Repeated Contact

```text
Might x Toughness x Conditioning

The Character follows a structured contact-training program intended to keep
the body coherent through repeated controlled impacts.
```

Conditioning supplies preparation and adaptation through training. Athletics
would describe performance during an athletic act, not the preparatory program
that precedes it. Medicine is not required because no injury is being assessed
or treated.

**Finding:** Conditioning has a distinct recurring function when it concerns
structured preparation and maintenance rather than current performance.

### Scenario B: Completing a Prolonged Climb

```text
Might x Vigor x Athletics

The Character sustains active output during a long technical climb.
```

Athletics supplies the practiced field of exertion. Conditioning may explain
why the Character arrived prepared, but it does not automatically contribute
again to the same climb. Counting both without separate fictional work would
double-count physical training.

**Finding:** Athletics remains distinct as present athletic performance.

### Scenario C: Diagnosing a Damaged Knee

```text
Psyche x Insight x Medicine

The Character interprets symptoms and test results to identify the injury.
```

Medicine supplies clinical knowledge and treatment practice. Rehabilitation
does not automatically contribute because identifying the injury is not yet a
restoration program.

**Finding:** Medicine remains distinct as assessment and treatment.

### Scenario D: Restoring Use After Injury

```text
Might x Resilience x Rehabilitation

The recovering Character follows a graded program to restore functional use
of the injured leg.
```

Resilience supplies the body's return toward baseline. Rehabilitation supplies
the learned restoration practice. Medicine may have established the diagnosis
or prescribed the program, but it contributes to this Expression only if
ongoing clinical treatment is performing separate work.

**Finding:** Rehabilitation has a coherent boundary, but its equal-cost value
depends upon whether extended physical recovery recurs often enough in the
Campaign Profile. In campaigns where it does not, Rehabilitation should remain
a Medicine or Conditioning Specialization rather than be preserved merely for
Anchor uniqueness.

### Scenario E: Regaining Composure Through Breath Control

```text
Psyche x Resolve x Meditation

The Character uses trained breathing and attention to maintain internal
direction through fear and pain.
```

Meditation supplies learned self-regulation. It may support recovery when the
fiction permits, but it does not create medical treatment or extraordinary
healing.

**Finding:** Meditation remains distinct because it governs internal practice,
not bodily training or clinical treatment.

### Scenario F: Ordinary Rest

```text
No Skill Expression is required.

The Character sleeps, eats, and rests under safe ordinary conditions.
```

Resilience and the recovery rules may resolve the return toward baseline
without requiring Rehabilitation, Medicine, Meditation, or Conditioning. A
Skill becomes relevant only when trained practice meaningfully changes an
uncertain recovery attempt.

**Test-One Result:**

```text
Athletics       Strong pass
Medicine        Strong pass
Meditation      Strong pass
Conditioning    Working pass with a preparation-and-maintenance boundary
Rehabilitation Conditional pass; Campaign Profile frequency must justify it
```

## Test Two: Solicitation and Persuasion

### Scenario A: Asking an Existing Contact for Routine Help

```text
Leverage x Network x Solicitation

The Character asks an established contact to provide information the contact
is ordinarily willing and positioned to share.
```

Network supplies the established relationship. Solicitation supplies learned
practice in making a usable request through that Network.

If the contact would plainly comply and no meaningful cost or uncertainty
exists, the Network may establish the result without a roll.

### Scenario B: Convincing a Reluctant Contact

```text
Influence x Connection x Persuasion

The Character develops present agreement with a reluctant contact through
argument and appeal.
```

Persuasion now carries the attempt because the target's present position must
change. The existing Network may grant Access to the conversation or supply
Resonance, but it does not replace the persuasive work.

### Scenario C: Organizing Support Through Many Existing Contacts

```text
Leverage x Network x Solicitation

The Character requests volunteers, donations, introductions, and information
from several established contacts for a relief effort.
```

This is broader than convincing one reluctant listener. It tests the ability
to activate an existing relational position around a request.

### Scenario D: Asking a Stranger

```text
Influence x Connection x Persuasion
```

With no relevant established Network, Solicitation cannot manufacture one.
The Character must create sufficient present connection and agreement through
the interaction itself.

### Scenario E: Public Fundraising Through Reputation

```text
Leverage x Reputation x Solicitation

The Character asks the public to support a cause because established public
standing gives the request weight.
```

The Skill remains Solicitation. Reputation, rather than Network, is the
established position making the request effective.

**Test-Two Result:**

Solicitation and Persuasion survive as distinct candidates if their boundary
is stated as:

```text
Solicitation activates support available through an established route.

Persuasion develops or changes present agreement.
```

They must not be stacked merely because every solicitation contains words
intended to persuade. Both may contribute only when one Lens establishes or
activates the route and the other performs a separate change in the target's
decision.

Solicitation receives a **working pass**. Its recurrence should be tested in
at least one investigation, political, organizational, or community-facing
Campaign Profile.

## Test Three: Endorsement and Automatic Reputation

### Scenario A: Recognition Without an Active Request

```text
No Endorsement Expression is required.

A proprietor recognizes the famous Character and provides a free meal.
```

Reputation establishes the fictional response, modifies Access, or supplies
contextual Resonance. The Character is not deliberately placing that standing
behind another subject.

### Scenario B: Publicly Vouching for Another Person

```text
Leverage x Reputation x Endorsement

The Character places established public credibility behind an accused ally.
```

Reputation supplies the standing at risk. Endorsement supplies learned public
sponsorship or vouching.

### Scenario C: Delivering the Endorsement Effectively

```text
Influence x Projection x Endorsement

The Character presents a prepared endorsement clearly to a skeptical public.
```

Projection supplies delivery. The Reputation truth may still be required for
the endorsement to carry its intended standing, but it is not automatically a
second numerical contribution unless it does distinct work.

### Scenario D: Infamous Standing

```text
Leverage x Reputation x Endorsement

A notorious figure publicly supports a criminal enterprise, lending it fear,
underworld credibility, and dangerous attention.
```

Reputation need not be favorable. The Expression asks whether the Character
can deliberately place that established public association behind a subject.

### Scenario E: Asking for Personal Favorable Treatment

```text
Leverage x Reputation x Solicitation

The Character asks for favorable treatment because public standing gives the
request weight.
```

This remains Solicitation. The Character is requesting support, not placing
their standing behind another person, claim, or cause.

**Test-Three Result:**

Endorsement describes a real deliberate function and passes the routing test.
It does not consume every passive or active use of Reputation. Its main risk is
Skill breadth: many campaigns may treat public sponsorship as a narrow
application of Persuasion, Arts, Commerce, or a Campaign Profile Skill.

Endorsement receives a **conditional working pass**. It is a useful teaching
anchor for Reputation, but its equal-cost status remains one of the two weakest
parts of the unique twenty-five-Skill requirement.

## Test Four: Enforcement and Command

### Scenario A: Directing a Team During a Crisis

```text
Influence x Control x Command

The Character coordinates willing or assigned participants through a rapidly
changing emergency.
```

Command supplies learned direction. It does not require recognized public
Authority when the participants are already willing or otherwise available to
be directed.

### Scenario B: Executing a Lawful Search

```text
Leverage x Authority x Enforcement

An authorized official applies an established warrant and search procedure.
```

Authority supplies the recognized right. Enforcement supplies learned
implementation of the rule or official decision. Neither creates the warrant,
office, jurisdiction, or current Access if those truths are absent.

### Scenario C: Issuing Orders Through an Office

```text
Leverage x Authority x Command

The Character directs an official response through a recognized chain of
command.
```

Command remains the Skill because coordinating people is the learned action.
Authority supplies the established route through which the order carries
force.

### Scenario D: Inspecting for Compliance

```text
Psyche x Awareness x Enforcement

The Character inspects a regulated site for observable violations using
learned enforcement procedure.
```

Awareness supplies detection. Enforcement remains the procedural field.
Authority may still be required for Access to the inspection, but Access is
not the same as effectiveness.

### Scenario E: Physically Carrying Out a Restriction

```text
Might x Strength x Enforcement

An authorized officer physically moves a barricade into place to close a
restricted route.
```

Strength supplies the immediate physical action. Enforcement remains relevant
only if implementing the official restriction involves learned procedural
practice beyond merely moving the object.

**Test-Four Result:**

Enforcement and Command survive if:

```text
Command coordinates available participants.

Enforcement implements an established rule, restriction, judgment, or official
decision.
```

Enforcement receives a **working pass**. Its anchor relationship depends upon
separating Authority as permission from Enforcement as learned procedure.

## Test Five: Arts Breadth

### Scenario A: Rehearsed Song

```text
Influence x Projection x Arts [Singing]

The Character delivers a rehearsed song so its intended emotional content
reaches an audience.
```

### Scenario B: Live Stage Presence

```text
Influence x Presence x Arts [Performance]

The Character holds the audience's attention through a live dramatic scene.
```

### Scenario C: Technical Dance

```text
Mobility x Coordination x Arts [Dance]

The Character executes a demanding choreographed sequence.
```

### Scenario D: Reading the Audience

```text
Psyche x Awareness x Arts [Performance]

The Character notices the audience losing attention and identifies the moment
at which the performance must change.
```

### Scenario E: Untrained Medium Transfer

```text
The Character has Arts [Singing] but has never learned sculpture.
```

The broad Arts Rank does not automatically make every artistic medium equally
available at full competence. Applicability and Specialization identify which
parts of the broad field the Character has actually practiced. A Campaign
Profile may promote a major medium to a separate Skill if it repeatedly needs
peer mechanical breadth.

**Test-Five Result:**

Arts survives as an instructional umbrella if the rules state clearly that:

```text
Arts does not grant undifferentiated mastery of every medium.

The declared medium must be supported by the Character's fiction, training,
or Specialization.
```

Arts receives a **working pass with breadth control**.

## Architecture Finding

The test does not reveal a broken Derived Attribute. Every tested Derived
Attribute supports a recognizable primary action.

It does reveal that the requirement for twenty-five unique Anchor Skills is
doing two different jobs:

```text
Teaching job
Give every Derived Attribute one memorable application.

Construction job
Offer Skills of sufficiently equal breadth and recurrence to share one Rank
and Training Point economy.
```

The teaching job succeeds across all twenty-five candidates.

The construction job remains unresolved for Rehabilitation and Endorsement,
and should still be observed for Conditioning, Solicitation, Enforcement, and
Arts. A good teaching example is not automatically an equal-cost Skill.

Therefore:

```text
Do not discard the twenty-five-anchor teaching architecture.

Do not yet treat uniqueness as proof that every Anchor belongs in every
Campaign Profile's active Skill economy.
```

## Next Test

Use the complete candidate set in one player-facing routing exercise:

1. Present the five Derived Attributes under one parent Attribute.
2. Present their five Anchor Skills and primary Expressions.
3. Give the player five new actions using those same Skills.
4. Ask the player to route each action through the Derived Attribute actually
   carrying it.
5. Record where the player relies on word association instead of fictional
   function.
6. Repeat once with a Skill crossing into another parent Attribute.

Run this first with Might because it contains the hardest physical boundaries.
Then run it with Leverage because it contains the newest architecture and the
two weakest equal-cost candidates.

The immediate question is no longer whether every Derived Attribute can be
illustrated. It can. The question is whether the Anchor set teaches correct
routing without falsely implying exclusive ownership or equal campaign value.
