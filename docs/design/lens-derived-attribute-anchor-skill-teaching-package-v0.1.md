# LENS Derived Attribute Anchor Skill and Teaching Expression Package

Version: 0.1  
Status: Working Candidate and Architecture Test; Does Not Supersede Current Skill Locks  
Date: 2026-09-01

---

## Purpose

Test a teaching architecture built around:

```text
25 Derived Attributes
25 unique Anchor Skills
25 primary teaching Expressions
50 lateral teaching Expressions
a larger illustrative Skill Index
Campaign Profile recommendations
player-proposed Skills
```

The Anchor Skills are real Skills available for character construction. Their
pairings are instructional rather than exclusive.

This package does not independently change:

```text
the 75 Training Point budget;
Skill Rank progression;
Specialization Rank progression;
the current 25-Active-Skill construction target;
or the current Skill and Specialization cost procedure.
```

It also does not yet replace the current fifteen-Core-Skill and Campaign
Profile presentation in the baseline draft. It tests a possible replacement
for that presentation.

---

## Teaching Architecture

```text
The Anchor list teaches.

The Skill Index suggests.

The Campaign Profile guides.

The Character selects and develops.
```

An Anchor pairing answers:

```text
What familiar learned field most clearly demonstrates this Derived Attribute
in action?
```

It does not answer:

```text
Which Derived Attribute permanently owns this Skill?
```

During play, the routing question remains:

```text
What capability or established position is actually making this action
effective?
```

---

## Anchor Skill Standards

Every Anchor Skill in this package is tested for the following:

```text
Training
It describes learned practice rather than raw capability.

Recurrence
It can matter repeatedly rather than describing one isolated maneuver.

Breadth
It supports several related applications and narrower Specializations.

Boundary
It does not merely restate its Anchor Derived Attribute.

Routing
Its primary and lateral Expressions change according to what actually carries
the action.

Permission
It does not create extraordinary permission, Access, equipment, authority, or
another truth that belongs to a different Lens.

Equal Cost
It is broad enough to be purchased through the same Training Point and Rank
procedure as other Skills.

Portability
It can be understood across multiple settings, or its Campaign Profile limits
are stated.
```

Uniqueness is a teaching preference, not permission to invent a weak Skill.

## Might Anchor Skills

### Strength -> Melee

**Skill definition:** Learned use of held close-range weapons to attack,
defend, and control immediate physical space.

```text
PRIMARY
Might x Strength x Melee

Drive an opponent backward with a forceful axe blow.
```

Strength supplies the primary Expression because generated physical force is
what makes the attack effective.

```text
LATERAL
Mobility x Coordination x Melee

Place a blade through a narrow opening in an opponent's guard.
```

Coordination now supplies the action because synchronized precision, rather
than maximum force, determines success.

```text
LATERAL
Mobility x Responsiveness x Melee

Intercept a sudden attack with a trained parry.
```

Responsiveness supplies the action because the Character must physically
adjust to a developing threat.

The learned field remains close-range weapon use in all three Expressions.

### Toughness -> Conditioning

**Skill definition:** Structured physical preparation used to make the body
tolerate repeated strain, contact, and demanding exertion while maintaining
readiness.

```text
PRIMARY
Might x Toughness x Conditioning

Complete a contact drill while absorbing controlled impacts without bodily
structure breaking down.
```

Toughness supplies the primary Expression because bodily coherence under
direct trauma is being tested.

```text
LATERAL
Might x Vigor x Conditioning

Sustain a demanding training circuit without losing output.
```

Vigor supplies the action because continued exertion, rather than impact
coherence, determines performance.

```text
LATERAL
Might x Resilience x Conditioning

Use a practiced cool-down and recovery routine after severe exertion.
```

Resilience supplies the action because the body is returning toward baseline.

The learned field remains structured physical preparation. The boundary
between Conditioning, Athletics, and Rehabilitation requires targeted review.

### Resistance -> Survival

**Skill definition:** Learned methods for maintaining life and function in
hazardous or resource-limited environments.

```text
PRIMARY
Might x Resistance x Survival

Maintain bodily function through prolonged cold using appropriate shelter,
clothing, hydration, and pacing.
```

Resistance supplies the primary Expression because an imposed environmental
condition is pressing against bodily function.

```text
LATERAL
Psyche x Awareness x Survival

Notice signs of dangerous weather and identify usable shelter before the storm
arrives.
```

Awareness supplies the action because receiving and attending to environmental
information determines success.

```text
LATERAL
Psyche x Insight x Survival

Interpret tracks, disturbed vegetation, and terrain to infer where an animal
went.
```

Insight supplies the action because the Character must recognize meaning and
relationships among observed signs.

The learned field remains hazardous-environment practice.

### Vigor -> Athletics

**Skill definition:** Practiced performance of demanding bodily movement,
exertion, and athletic technique.

```text
PRIMARY
Might x Vigor x Athletics

Maintain a prolonged climb without losing active physical output.
```

Vigor supplies the primary Expression because sustained exertion determines
whether the Character can continue.

```text
LATERAL
Mobility x Movement x Athletics

Sprint across open ground before a gate closes.
```

Movement supplies the action because physical relocation is the immediate
objective.

```text
LATERAL
Mobility x Coordination x Athletics

Execute a technically precise jump onto a narrow landing.
```

Coordination supplies the action because synchronized bodily execution is
doing the work.

The learned field remains athletic practice. Running, climbing, swimming,
jumping, throwing, and weightlifting remain possible Specializations.

### Resilience -> Rehabilitation

**Skill definition:** Planned restoration of lost bodily function through
graded exercise, mobility work, adaptation, and recovery protocols.

```text
PRIMARY
Might x Resilience x Rehabilitation

Restore functional use of an injured leg through a sustained recovery program.
```

Resilience supplies the primary Expression because the body is returning
toward its prior physical baseline after disruption.

```text
LATERAL
Psyche x Learning x Rehabilitation

Recall and correctly follow the stages of an established recovery protocol.
```

Learning supplies the action because acquired procedure and retention are
carrying the attempt.

```text
LATERAL
Mobility x Coordination x Rehabilitation

Perform a controlled therapeutic movement without placing the recovering
joint outside its permitted path.
```

Coordination supplies the action because precise movement execution determines
whether the exercise is performed correctly.

The learned field remains restoration practice. This candidate requires an
equal-cost and recurrence test against Medicine and Conditioning. If it proves
too narrow, it should become a Specialization rather than remain a Skill merely
to preserve a unique Anchor.

## Routing Validation

The completed candidate set contains:

```text
25 Derived Attributes
25 unique Anchor Skills
25 primary teaching Expressions
50 lateral teaching Expressions
```

Every primary and lateral Expression retains the same Skill while changing the
capability or established position carrying the action.

No lateral example changes routing solely because another Derived Attribute
could be associated with the same word. Each example changes what is actually
making the action effective.

| Assets | Trading | Recurring exchange practice | Material commitment, analysis, and negotiation remain distinct | Does not create goods, availability, legality, or purchase Access | Working control |
| Network | Solicitation | Recurring in relationship-facing campaigns | Existing relationships, Reputation, and present Connection remain distinct | Does not manufacture contacts or agreement | Working pass |
| Authority | Enforcement | Recurring in institutional campaigns | Official right, present regulation, observation, and physical implementation remain distinct | Does not create office, jurisdiction, or legal Access | Working pass |
| Reputation | Endorsement | Deliberate public sponsorship recurs unevenly by campaign | Public, communicative, and community routes remain distinct | Does not replace passive Reputation responses | Conditional pass |
| Background | Language | Recurring communication practice | Formation, study, and deliberate communication remain distinct | Requires a fictional basis for the particular language | Strong working control |

The table distinguishes three questions that should not be collapsed:

```text
Can the Skill teach the Derived Attribute?

Can the Skill route laterally without changing learned fields?

Does the Skill recur broadly enough to share the same construction economy in
the active Campaign Profile?
```

All twenty-five candidates pass the first two questions. Rehabilitation and
Endorsement remain unresolved on the third. Conditioning, Solicitation,
Enforcement, and Arts pass provisionally but retain explicit scope controls.

## Boundary Watch List

### Conditioning / Athletics / Rehabilitation

Current proposed boundary:

```text
Conditioning
Prepares and maintains the body for repeated strain, contact, and demanding
use.

Athletics
Performs demanding bodily movement and exertion.

Rehabilitation
Restores lost function after disruption.
```

Risk:

Conditioning and Rehabilitation may prove too narrow or too dependent upon the
same practices to justify equal-cost peer Skills.

Required test:

Build ordinary training, injury recovery, long-exertion, and environmental
adaptation scenes. Determine whether each field repeatedly performs a distinct
job and supports several Specializations.

### Solicitation / Persuasion

Current proposed boundary:

```text
Solicitation
Requests contribution through a person or group available to be asked.

Persuasion
Changes a willing listener's position through argument, appeal, negotiation,
or mediation.
```

Risk:

If every difficult request becomes Persuasion, Solicitation may be only a
Network application rather than a peer Skill.

Required test:

Compare fundraising, calling in favors, recruiting volunteers, negotiating,
and persuading a reluctant stranger.

### Endorsement / Automatic Reputation

Current proposed boundary:

```text
Automatic Reputation response
The established public truth changes behavior without a deliberate trained
attempt.

Endorsement
The Character deliberately places that public standing behind another subject.
```

Risk:

Endorsement may describe a result more than a learned recurring field.

Required test:

Compare vouching, sponsorship, advocacy, public recommendation, brand
association, and passive recognition across several scenes.

### Enforcement / Command

Current proposed boundary:

```text
Enforcement
Applies an established rule or official decision through recognized authority
and procedure.

Command
Directs and coordinates participants who are available to be directed.
```

Risk:

Enforcement may collapse into Authority Access plus Command, Security, or a
professional procedure if it does not contribute a distinct learned method.

Required test:

Compare inspection, arrest, sanction implementation, emergency requisition,
crowd direction, and battlefield command.

### Arts Breadth

Current proposed boundary:

Arts remains one broad Skill because Derived Attribute routing and
Specializations distinguish creation, performance, medium, and purpose.

Risk:

The field may become broader than other equal-cost Skills if every artistic
medium and live performance is assumed applicable without a relevant
Specialization or fictional basis.

Control:

Applicability must require a relevant medium or practice. A broad Rank does not
make every artistic form equally applicable.

## Campaign Profile Guidance

A Campaign Profile should:

```text
1. Identify the learned fields expected to recur in play.

2. Recommend Skills that help Characters engage those fields.

3. Add, split, merge, or rename Skills when the setting gives them equivalent
   recurring breadth.

4. State which equipment, institutions, languages, technologies, creatures,
   traditions, or extraordinary practices require Access.

5. Identify any Skills whose ordinary scope changes in that setting.

6. Preserve the common Rank, Training Point, routing, applicability, and
   Specialization procedures.

7. Avoid treating recommendations as mandatory purchases or free Ranks.
```

The Anchor list remains available as a teaching reference even when a Campaign
Profile recommends a very different practical Skill selection.

## Player-Proposed Skill Guidance

A player may propose another Skill by explaining:

```text
what learned field it represents;

why that field recurs in the campaign;

what actions it covers;

what it does not cover;

which narrower Specializations it could support;

and what fictional basis makes it available to the Character.
```

The proposed Skill must:

```text
have breadth comparable to existing Skills;

use the same Rank and Training Point costs;

route through whichever Derived Attribute actually carries the current action;

not manufacture Classification, Access, a HOLT, equipment, authority, or
another permission-bearing Lens;

and not receive free Ranks merely because the proposal is approved.
```

If the proposal is narrower than a peer Skill, it should normally become a
Specialization. If it is broader than several peer Skills, it should be
narrowed or divided according to the campaign's actual recurring practices.

## First-Pass Findings

```text
STRONG PASS:
The Anchor architecture teaches Derived Attribute routing more clearly than a
bare Skill list.

STRONG PASS:
Twenty-five unique candidate Skills can be produced without assigning Skills
permanently to Derived Attributes.

STRONG PASS:
The fifty lateral Expressions demonstrate that the same learned field can be
carried through different capabilities or established positions.

PASS:
The architecture preserves the Skill and Specialization layers and does not
require a new mathematical subsystem.

PASS:
The existing Skill Index and Campaign Profile model can remain available
without a closed universal catalogue.

PASS WITH BOUNDARY TESTS:
Conditioning, Rehabilitation, Solicitation, Enforcement, and Endorsement need
targeted recurrence, overlap, and equal-cost testing.

CAUTION:
Uniqueness must remain subordinate to natural language and Skill breadth. A
weak Anchor Skill should not be preserved merely to complete a twenty-five
entry symmetry.

NOT ADOPTED:
Removal of the current fifteen Core Skills.

NOT ADOPTED:
The twenty-five candidate Anchor Skills as a final list.

NOT CHANGED:
The 75 Training Point budget, Rank progression, Specialization procedure, or
current construction economy.
```

## Recommendation

Advance this architecture to focused playtesting.

Use the complete roster as the teaching-set candidate while testing the five
boundary risks directly. Do not revise the baseline Core/Profile Skill
architecture until those tests answer whether the Anchor presentation is
clearer and whether every candidate remains a full equal-cost Skill.

The first targeted test should compare:

```text
Conditioning
Athletics
Rehabilitation
Medicine
Meditation
```

across physical preparation, sustained exertion, environmental stress, injury,
recovery, and treatment scenes. That test carries the greatest risk of finding
a forced Skill created only to preserve the one-to-one Anchor pattern.
