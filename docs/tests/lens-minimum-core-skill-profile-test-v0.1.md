# LENS Minimum-Core Skill Profile Test

Version: 0.1  
Status: Working Architecture Test  
Purpose: Determine which Skills, if any, must be named by the universal LENS
engine and which Skills should instead be selected by Campaign Profiles,
created by players, or presented in an appendix library.

Nothing in this record adopts a final Skill list, Campaign Profile, Skill
count, or character-creation rule.

---

## Question Under Test

```text
What must LENS provide universally, and what should each setting or campaign
select or create?
```

The previous boundary test established that thirty concepts could function as
valid Skills. It did not establish that all thirty concepts must appear on
every character sheet.

This test separates two questions:

```text
Is this a valid Skill?

Must the universal engine name this Skill in advance?
```

---

## External Design Control

An independent evaluation identified the following distinction:

```text
GURPS asks:
"How do we accurately model this capability?"

LENS asks:
"Which truths are carrying force in this Expression?"
```

This distinction is used as a test control rather than adopted doctrine.

The Skill procedure should therefore test contextual participation, not only
catalogue coverage and point-buy efficiency.

---

## Test Controls

Four deliberately different Campaign Profiles were constructed:

```text
Grounded Urban Investigation
Heroic Frontier Fantasy
Future-Tech Exploration
Superhero Team Adventure
```

Each profile receives exactly fifteen featured Skills for comparison.

The number fifteen is a test control, not a recommended final count.

A featured Skill means:

```text
The Campaign Profile expects this learned method to recur often enough that
naming it in advance is useful.
```

An omitted Skill does not become forbidden.

When a named Skill is absent, the Character may still:

```text
use the applicable Attribute or Derived Attribute without trained support;

create or purchase an appropriately broad Skill if character creation permits;

use a Skill supplied by the Campaign Profile or appendix library;

or rely on another applicable Lens when the fiction supports it.
```

Extraordinary permission continues to come from Classification, HOLT, Access,
or another permission-bearing Lens. A Skill does not create extraordinary
permission merely because it has been named.

## Profile A: Grounded Urban Investigation

Campaign premise:

```text
Ordinary human investigators operate inside a modern city, gather evidence,
navigate institutions, pursue suspects, and sometimes face direct violence.
```

Featured Skills:

```text
Athletics
Stealth
Vehicle Operation
Unarmed Combat
Ranged Combat
Investigation
Research
Medicine
Security
Persuasion
Deception
Intimidation
Streetwise
Administration
Protocol
```

Representative applications:

```text
Athletics through Strength or Movement:
climb a fire escape or force through a physical obstruction.

Investigation through Awareness:
locate physical evidence at a crime scene.

Investigation through Insight:
interpret how several pieces of evidence relate.

Security through Cognition:
understand the design of an alarm system.

Security through Control:
disable that alarm without triggering it.

Protocol through Learning or Connection:
follow institutional procedure and recognize how to approach an official.
```

Omission test:

```text
Scholarship is not featured.

An investigator may still attempt to recall historical or scientific
information through Learning. A scholarly investigator may add Scholarship.
The campaign does not require every investigator to purchase it.
```

Result:

```text
The profile remains functional without treating every valid learned field as
a universal entry.
```

```text

treatment, or investigation.
```

A court drama, generational community game, political administration game, or
ritual-magic academy would produce a different intersection.

## Minimum-Core Test

A Skill qualifies as mandatory universal content only if all four statements
remain true:

```text
1. The learned method recurs across substantially different Campaign Profiles.

2. Its breadth remains meaningfully equivalent across those Profiles.

3. The engine requires the Skill to be named before a Campaign Profile exists.

4. Removing the named Skill prevents ordinary resolution or requires a new
   subsystem.
```

Test result:

```text
No candidate satisfies all four requirements.
```

Several candidates recur across the four tested adventure Profiles, but none
must be named by the universal engine before the campaign is known.

Ordinary attempts continue to resolve through applicable Attributes and
Derived Attributes. Training can be added through a Profile-selected,
player-created, or appendix-supplied Skill.

This does not mean Skills are optional during character construction once a
Campaign Profile selects them. It means the universal engine may not need one
mandatory content list.

## LENS-Specific Routing Test

Three recurring Skills were checked across multiple fictional uses.

### Investigation

```text
Awareness:
notice evidence.

Insight:
interpret relationships among evidence.

Learning:
connect evidence to retained disciplinary knowledge.

Control or Coordination:
reconstruct or experimentally reproduce a physical sequence.
```

### Vehicle Operation

```text
Coordination:
perform precise physical control.

Awareness:
detect hazards while operating.

Cognition:
manage a complex operating sequence.

Control:
direct a remote, networked, or externally projected vehicle system.
```

### Medicine

```text
Learning:
diagnose from trained knowledge.

Awareness:
notice symptoms or changing condition.

Control or Coordination:
perform a precise intervention.

Connection:
establish cooperation, reassurance, or therapeutic rapport when relevant.
```

Finding:

```text
The Skill names the learned method.

The fiction identifies which Derived Attribute expresses that method in the
current action.

The Skill therefore does not need a fixed Attribute assignment or a separate
procedure for each application.
```

## Appendix Test

The thirty candidates remain useful when reframed as an appendix library.

Each appendix entry may provide:

```text
Skill name
functional scope
sample Derived Attribute routes
sample Specializations
possible Campaign Profiles
important Access or permission boundaries
```

The appendix does not declare that every entry exists, is equally common, or
must appear in every campaign.

Example profile guidance:

```text
Science campaign:
Research, Scholarship, Medicine, Engineering, Security, and relevant
Specializations.

Future technology campaign:
Engineering, Vehicle Operation, Security, Medicine, and setting-defined
Specializations such as Robotics, Cybernetics, or Starship Systems.

Court intrigue campaign:
Protocol, Persuasion, Deception, Administration, Research, and Scholarship.

Wilderness fantasy campaign:
Athletics, Survival, Animal Handling, Navigation, Medicine, and Craft.
```

---

## Findings

```text
1. Thirty valid Skill concepts do not produce thirty mandatory core Skills.

2. A Skill can be mechanically valid without belonging on every character
   sheet.

3. Campaign premise determines Skill relevance more strongly than genre alone.

4. The strict intersection of four adventure Profiles reflects adventure
   conventions, not universal LENS requirements.

5. No content Skill proved mandatory to the universal engine.

6. Attributes and Derived Attributes preserve ordinary untrained action when
   a Skill is absent.

7. Profile-selected and player-created Skills can represent trained methods
   without requiring new resolution rules.

8. The same Skill routes through different Derived Attributes according to
   the declared Expression and fiction.

9. Extraordinary capabilities remain outside the Skill catalogue and continue
   to use the higher-order architecture.

10. The thirty-candidate bank remains valuable as an appendix Skill Library.
```

---

## Working Recommendation Produced by Test

```text
Universal LENS should define the Skill grammar rather than require one fixed
universal Skill catalogue.

Each Campaign Profile should select or create the Skills that represent its
recurring learned methods.

The core book may still provide a compact conventional-adventure starter list,
but that list should be labeled as an implementation example rather than the
universal engine.

The broader candidate bank should become an appendix Skill Library containing
possible conceptual Skills, routing examples, Specializations, and Campaign
Profile guidance.
```

This recommendation is a test result, not adopted doctrine.

## Impact on Previous Tests

The earlier thirty-Skill character test remains valid for the question it
actually tested:

```text
Can three Characters distribute the same Training budget differently across a
large available Skill catalogue and remain functional?
```

It does not establish that the catalogue must be universal.

The earlier specialization-applicability test should remain deferred until the
Skill source and Profile procedure are clearer.

---

## Exact Next Decision

```text
Should LENS adopt the working direction that the universal engine defines Skill
construction and use, while Campaign Profiles select the active Skill list and
the core book provides examples rather than a mandatory universal catalogue?
```

## Post-Test Working Decision

Status:

```text
WORKING LOCK FOR CURRENT CONSTRUCTION AND PLAYTESTING
```

After direct review of the thirty candidates, the current working core was set
at fifteen Skills:

```text
Athletics
Stealth
Survival

Unarmed Combat
Melee
Ranged Combat
Tactics

Investigation
Medicine
Language
Security

Persuasion
Deception
Command
Intimidation
```

Tactics was promoted from a core contender to the working core.

The earlier `Linguistics` contender was separated into two concepts:

```text
Language
= functional ability to understand, speak, read, write, and communicate

Linguistics
= analytical study of language structure and development
```

`Language` enters the working core. `Linguistics` remains an appendix or
Campaign Profile candidate. The fiction establishes which languages the
Character has a basis for knowing or interpreting; the Skill does not become
applicable to every unknown language automatically.

The remaining candidates are preserved for Campaign Profiles, player-created
Skills, and the appendix Skill Library. They were not rejected as invalid
Skills.

The fifteen-Skill list is a working construction and playtest control. It is
not asserted to be the only Skill list a LENS implementation may use.

## Active List Construction Decision

Status:

```text
WORKING LOCK FOR CURRENT CONSTRUCTION AND PLAYTESTING
```

The working active Skill list contains twenty entries:

```text
15 Core Skills
+ 5 Campaign Profile Skills
= 20 Active Skills
```

The five Campaign Profile Skills are selected from the appendix Skill Library
or defined at equivalent breadth for the specific campaign. They use the same
rules and costs as Core Skills.

This produces the following current construction comparison:

```text
20 Derived Attributes with 40 Derived Attribute Points
= average Rank 2 if distributed evenly

20 Active Skills with 60 shared Training Points
= average Rank 3 if distributed evenly and no points are spent on
   Specializations
```

The averages are diagnostic only. They do not require even distribution.

This decision preserves a compact universal core while allowing each Campaign
Profile to give five learned fields particular mechanical prominence without
creating a separate Skill procedure.

The Active Skill list is not a closed catalogue. A player may propose another
Skill by explaining its learned field and place within the campaign's scope and
fiction. A scope-equivalent proposal that makes sense becomes available under
the same Skill rules and must be purchased from the same Training pool; it does
not grant free Ranks or extraordinary permission.
