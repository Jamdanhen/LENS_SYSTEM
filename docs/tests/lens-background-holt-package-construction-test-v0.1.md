# LENS Background HOLT Package Construction Test

Version: 0.1  
Status: Superseded Working Construction and Compensation Test  
Date: 2026-08-31

> Supersession note: The later Leverage fifth-Attribute test replaces this
> record's six-umbrella Background HOLT architecture as the current leading
> candidate. This file remains a historical test record. Its limitation,
> compensation, and exposure findings remain useful where they do not depend on
> Resources, Connections, Standing, Profession, Disposition, and Origin being
> six separately ranked HOLT routes.

---

## Purpose

This test follows the Background Capacity third-locus test.

It builds three provisional Background HOLT packages:

```text
Broad Character
Focused Character
Exposed Character
```

The test evaluates:

```text
whether the six provisional Background umbrellas can produce distinct builds;
whether equal Background Capacity preserves meaningful comparison;
whether Background Load affects broad and focused Characters coherently;
whether Exposures or Limitations may increase Background Capacity safely;
and whether one limitation can be compensated twice.
```

Nothing in this record adopts final starting budgets, HOLT costs, umbrella
Ranks, Capacity increases, limitation values, or Campaign Profile numbers.

---

## Existing Controls Preserved

```text
The Character remains the source of action.

The HOLT establishes a coherent Character-facing theme.

The parent HOLT Rank is not a universal multiplier.

The HOLT Rank caps development beneath it.

An unranked expression route may grant permission but supplies no
HOLT-derived modifier.

No relevant Lens contribution is counted twice.

Naturally connected drawbacks belonging to a complete Character Lens cannot
be claimed again as separate compensation.
```

```text

```

For this test:

```text

Rank 1 = x1.1
Rank 2 = x1.2
Rank 3 = x1.3
Rank 4 = x1.4
Rank 5 = x1.5

```

The HOLT Rank 6 caps each umbrella Rank at 6.

The twelve-Rank allocation is deliberately held equal. It is not a proposed
starting budget.

The umbrella Rank occupies one Background HOLT contribution slot in the test.
It does not stack with a second numerical contribution from the same HOLT.
The ordinary Attribute, Derived Attribute, Skill, and Specialization route
still establishes the Character's underlying competence.

This last control is necessary to prevent the provisional Background
structure from multiplying itself twice. Its final relationship to the locked
HOLT Axis architecture remains unresolved.

## Test 1: Broad Versus Focused Capability

The diagnostic Base Expression is 80.

At Background Load 0:

```text
Character A: Community Fixer

Any ranked umbrella:
80 x 1.2 = 96

Character B: Industrial Magnate

Resources:
80 x 1.6 = 128

Connections:
80 x 1.4 = 112

Standing:
80 x 1.2 = 96

Unranked route when permission applies:
80 x 1.0 = 80
```

Finding:

```text
PASS

Equal umbrella allocations produce a real breadth-versus-focus tradeoff.

The broad Character has moderate leverage through six functions.

The focused Character has substantially greater leverage through two
functions while retaining only baseline permission elsewhere.

Neither distribution is universally superior.
```

## Test 4: Development Compensation

Candidate compensation:

```text
The applicable HOLD values the Royal Envoy Standing limitation at two
development Ranks.

Those Ranks must remain inside the Royal Envoy HOLT.
```

Illustrative reinvestment:

```text
Connections: Rank 5 becomes Rank 6
Profession:  Rank 2 becomes Rank 3

Revised total umbrella Ranks: 14
```

The Standing Rank remains 5 with Condition Access.

Finding:

```text
CONDITIONAL PASS

The Character becomes stronger elsewhere inside the same HOLT but retains a
real, targetable restriction on Standing.

The value of two Ranks is illustrative only. Exact values remain HOLD- and
Campaign-Profile-dependent.
```

## Test 5: Background Capacity Compensation

Alternative candidate:

```text
The same Standing limitation increases Background Capacity from 10 to 12.
```

This creates a global benefit.

The Character now withstands more pressure against:

```text
Resources;
Connections;
Standing;
Profession;
Disposition;
Origin;
and every other Background HOLT the Character may possess.
```

The limitation affects one Standing route. The compensation protects the
entire Background architecture.

At Load 6:

```text
Capacity 10 Character:
Load 6 is beyond half Capacity.
Function Band = 50%

Capacity 12 Character:
Load 6 is exactly half Capacity.
Function Band = 75% under the proportional translation test.

Royal Envoy Connections Rank 5:

Capacity 10:
80 x 1.5 x 0.50 = 60

Capacity 12:
80 x 1.5 x 0.75 = 90
```

The local Standing limitation has increased an unrelated Connections
Expression by 50% at the same Load.

Finding:

```text
FAIL AS A GENERAL EXCHANGE

A limitation affecting one HOLT route should not directly purchase global
Background Capacity.

The exchange is broader than the sacrifice and becomes an attractive
optimization choice.
```

## Test 6: Capacity-Wide Exposure

A broader exposure may pressure the entire Background structure.

Example:

```text
False Identity

Exposure threatens Resources, Connections, Standing, Profession, and Origin
whenever the identity is investigated or broken.
```

This exposure is closer in scope to Background Capacity than the Royal Envoy
Standing limitation.

Candidate exchange:

```text
Accept a Capacity-wide Exposure.

Receive a HOLD-defined increase to Background Capacity.

Receive no separate HOLT development compensation for that same Exposure.
```

Finding:

```text
CONDITIONAL PASS

An Exposure may potentially purchase Background Capacity only when its scope
can meaningfully pressure Background function as a whole.

The Exposure must be mechanically targetable, occur often enough to matter,
and exceed the HOLT's naturally connected counterplay.

The exact increase remains unresolved.
```

## Test 7: Double Compensation

Candidate exploit:

```text
Take one Limitation.

Receive two development Ranks inside the HOLT.

Also increase Background Capacity.
```

Result:

```text
FAIL

The same sacrifice has been paid twice.
```

Control:

```text
One formal Limitation or Exposure receives one compensation function.

Local limitation:
May return local development value under the HOLT.

Capacity-wide exposure:
May potentially increase Background Capacity under the Campaign Profile.

The same restriction cannot do both.
```

## Test 8: Variable Capacity Function Bands

Campaign Profile variation and Character-specific Capacity increases require
the Function Bands to translate proportionally.

If the fixed Load 0-2, 3-5, 6-7, and 8-9 bands were used for every Capacity,
increasing Capacity above 10 would provide extra collapse space without
changing the earlier Function Bands coherently.

Candidate proportional rule:

```text
Load below 25% of Capacity:
100% Function Band

Load from 25% through 50% of Capacity:
75% Function Band

Load above 50% through 75% of Capacity:
50% Function Band

Load above 75% but below 100% of Capacity:
25% Function Band

Load at or above 100% of Capacity:
loss or exhaustion of the affected function
```

Translations:

```text
CAPACITY 8

Load 0-1 = 100%
Load 2-4 = 75%
Load 5-6 = 50%
Load 7   = 25%
Load 8+  = function lost or exhausted

CAPACITY 10

Load 0-2 = 100%
Load 3-5 = 75%
Load 6-7 = 50%
Load 8-9 = 25%
Load 10+ = function lost or exhausted

CAPACITY 12

Load 0-2  = 100%
Load 3-6  = 75%
Load 7-9  = 50%
Load 10-11 = 25%
Load 12+   = function lost or exhausted
```

Finding:

```text
PASS AS A MATHEMATICAL TRANSLATION CANDIDATE

The proportional rule reproduces the current Capacity 10 bands and allows
Campaign Profiles to change Capacity without creating a separate table by
intuition.

The boundary wording and rounding procedure require confirmation before this
becomes a working lock.
```

## Test 9: Umbrella Boundary Check

The three builds reveal different levels of mechanical clarity.

```text
Resources
Strong fit when Rank measures mobilizable material leverage rather than exact
currency or equipment effectiveness.

Connections
Strong fit when Rank measures effective relational or network leverage rather
than another Character's obedience.

Standing
Strong fit when Rank measures effective recognized status, authority,
credential, or reputation within its established scope.

Profession
Conditional fit when Rank measures professional identity and Access. It must
not replace Skill or Specialization competence.

Origin
Conditional fit when Rank measures effective inherited, cultural, historical,
or legacy leverage. It must not replace Classification or learned knowledge.

Disposition
Weakest numerical fit. Internal resolve, awareness, compulsion, or emotional
pressure may already belong to Psyche or Mental Capacity. Disposition remains
useful as a stable truth, exposure, obligation, or permission, but its use as
a general Background multiplier requires additional testing.
```

Finding:

```text
CONDITIONAL PASS

The six umbrellas work as an organizational map.

Five can produce distinguishable Background leverage with clear boundaries.

Disposition requires a dedicated overlap test before it should be treated as
an equal numerical route.
```

## Consolidated Findings

```text
PASS
Equal allocation creates meaningfully different broad and focused Characters.

PASS
Equal Background Capacity preserves comparison between those builds.

PASS
Global Background Load pressures both builds without erasing their relative
strengths.

PASS
Specific Access Conditions can restrict one part of a Background HOLT.

CONDITIONAL PASS
Formal local Limitations may return development value inside the same HOLT.

FAIL
A local Limitation should not purchase global Background Capacity.

CONDITIONAL PASS
A genuinely Capacity-wide Exposure may potentially purchase Background
Capacity if it receives no other compensation.

FAIL
One Limitation or Exposure cannot purchase both development and Capacity.

PASS AS A CANDIDATE
Variable Capacity can use proportionally translated Function Bands.

CONDITIONAL PASS
The six umbrellas support the package test, but Disposition requires further
boundary testing.
```

---

## Primary Design Findings

```text
1. Broad and focused Background characters can use one construction grammar.

2. Background Capacity should remain equal inside a Campaign Profile unless a
   Character purchases a specifically authorized exception.

3. Compensation must remain proportional to the scope of the restriction.

4. Local HOLT restrictions return local HOLT development.

5. Only Capacity-wide Exposures can plausibly purchase Background Capacity.

6. One restriction receives one compensation function.

7. Capacity variation requires proportional Function Band thresholds.

8. The Background umbrella Rank must occupy one HOLT contribution slot rather
   than stacking with a second contribution from the same HOLT.
```
