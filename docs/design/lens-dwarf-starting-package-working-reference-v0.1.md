# Dwarf Starting Package: Working Comparison Reference

Status: Setting-specific construction test reference, not a universal dwarf
Classification or final adopted package. The user approved x1.10/x0.90 as
working test values. Final values and overall balance remain unresolved.

## Current Test Package

```text
Darkvision
Granted sensory Access in darkness, with limits still to be defined by the
setting. No automatic numerical bonus or free Awareness Rank.

Natural-Poison Resistance
x1.10 relevant Resonance to Resistance Expressions against naturally
occurring poisons. No immunity or automatic Condition mitigation.

Stone Observation
x1.10 relevant Resonance to Observation Expressions involving stone,
stonework, gems, or precious metals. No automatic hidden-information Access,
appraisal knowledge, or crafting expertise.

Dense Build
x0.90 relevant Dissonance when bodily density hinders jumping, buoyancy,
or crossing weight-sensitive surfaces. Jumping can qualify on sound supports.
No blanket Mobility penalty or automatic closure of swimming Access.
```

Relevant contributions use the existing Expression and aggregation procedure.
The two Resonance traits do not automatically multiply together; their stated
applications are distinct. Unrelated actions receive neither bonus nor penalty.
Do not require rolls for routine activities merely to demonstrate a trait.

## Provision Model

Test as a setting-defined starting package with approved variants, without a
mandatory player-facing provision pool. The Campaign Profile supplies the
intended common provision level; the applicable HOLD specifies grants,
development options, and limitations. No level or point allowance is set here.

The negative remains part of the whole package and is not also claimed as
separate compensation. The 25 / 50 / 100 ordinary construction pools remain
unchanged. Human provisions are not invented or removed from future comparison.

## Variant Candidates

- Expanded variant: retain all features and add the tested local-contact stone
  sense. This is more provision, not an automatically free addition.
- Exchange variant: replace Stone Observation Resonance with that sense while
  retaining darkvision, poison Resonance, and Dense Build. This creates a
  real tradeoff but is not an approved equal-value exchange.

The candidate sense permits attempts to perceive a concealed fracture in a
touched stone section or a hollow immediately behind it without ordinary clues.
It grants no numerical bonus, remote geological survey, or detailed room
contents. Range and precise permission boundaries remain setting decisions.
