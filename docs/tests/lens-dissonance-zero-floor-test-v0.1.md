# Dissonance Remaining-Factor Zero Floor

Status: Historical candidate test, superseded by the adopted combined-factor
floor in `lens-resonance-dissonance-offset-comparison-v0.1.md`. Do not apply
this separate Dissonance floor before offsetting Resonance. Arithmetic below
is preserved as comparison evidence, not current resolution procedure.

## Candidate and Controls

Let t be the total applicable, distinct Dissonance reduction. Proposed
remaining factor D = max(0, 1 - t). Apply the existing separate-pool Expression
B x R x D and floor the final Rating normally. This is a lower bound on the
resulting factor, not a ceiling on source values or total actual interference.

Preserve the adopted ten-percent assessment increments, all existing defined
values, one assessed environmental contribution, no duplicate Condition
penalties, Access, and the natural-01 continuation for permitted zero-Rating
attempts. B contains unchanged noncontextual factors. No additional Difficulty
is assigned. The candidate does not merge Resonance and Dissonance or introduce
a new Condition track.

Sources: current baseline Current Roll Budget, natural-01 procedure, and
`lens-contextual-ten-percent-steps-test-v0.1.md`.

| 110% | 0 | 0 |
| 130% | 0 | 0 |
| 150% | 0 | 0 |
| 200% | 0 | 0 |

Sub-100% results are unchanged. Increasing interference never improves the
result or produces negative effectiveness. Contribution order does not matter.

## Excess Interference Must Remain Real

Use three distinct applicable Lens reductions of 0.60, 0.50, and 0.20:

```text
Together:                  1.30 reduction -> factor 0
Remove the 0.20 source:    1.10 reduction -> factor 0
Instead remove 0.50:      0.80 reduction -> factor 0.20
```

If the sum had been stored as only 1.00 and the excess discarded, removing
0.20 would incorrectly restore factor 0.20. Retain the actual Lenses and
reassess their applicability when circumstances change. No separate excess
Load track, favor meter, or permanent accumulation is needed.

For example, clearing an environmental obstruction may remove one assessed
source while other genuinely distinct interference remains. It does not
necessarily restore numerical effectiveness immediately. The displayed result
can stay at zero even though the fictional situation has improved.

## Resonance, Access, and Exceptional Results

Separate multiplication makes zero decisive: R=1, 1.50, or 2 cannot rescue
D=0. The paid +0.20 changes R, not the interference sources. This is a real
design consequence, not merely an implementation detail. Characters can
address sources, change to a route where they do not apply, or attempt an
otherwise permitted action using the existing exceptional-roll procedure.
A counter-Lens that specifically answers interference is evaluated for that
actual function, not presumed to be another generic positive multiplier.

A zero numerical Rating does not independently close Access. Initial01 then06
gives adjusted result -93; at Rating0 that yields ten generated Effects before
normal matching mitigation and other Effect handling. Initial01 then00 leaves
1 and fails at Rating0. Neither example changes Scope or permits a forbidden
action. These outcomes already follow the accepted special-result rule.

If the fiction closes Access, no roll occurs. If it makes an action Automatic,
do not force a roll to demonstrate this calculation. A Function Band remains
its separate existing factor; a Condition already represented there is not
added again to t. A distinct 50% contextual reduction with B60 and a separate
75% Function Band yields 22.5, floored to22.

## Verification and Recommendation

`lens-dissonance-zero-floor-test-v0.1.ps1` completed 96 arithmetic cases and
390 checks across four B values, three R factors, and eight reduction totals.
Additional assertions cover changing sources, ordering, an independent Function
Band, and the two natural-01 examples. No complete dice-probability or live-play
claim is made.

Recommend the zero floor while retaining actual contributing Lenses. This
prevents negative effectiveness without inventing a limit on how much
interference may exist. Adoption must acknowledge that generic Resonance does
not overcome a zero remaining factor, while permitted exceptional attempts
remain possible. No change to additive pooling is proposed.
