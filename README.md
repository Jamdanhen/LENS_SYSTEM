# LENS System

## Purpose

LENS is a reusable system engine for narrative architecture, expression system
rules, game mechanics, and system-neutral design work.

It began as material developed in the MOTU TTRPG project, but now has its own
authority as a standalone project.

## Authority Location

```text
C:\LENS-System
```

This folder is the source of truth for LENS until another source of truth is
explicitly identified.

GitHub repository:

```text
https://github.com/Jamdanhen/LENS_SYSTEM
```

OneDrive, sync folders, mirrors, and interface folders are copies only unless
the user explicitly makes one of them the source of truth.

## Boundary

LENS owns:

- system-neutral LENS engine doctrine
- Scale, Difficulty, Classification, Resonance, and Dissonance design
- expression system rules
- game mechanics
- LENS-specific tests, modules, settings, and implementation notes

LENS does not own:

- MOTU TTRPG source material
- MOTU setting lore, factions, artifacts, names, or licensed-adjacent material
- REflections source material
- Comics / Around Here creative canon
- Crucible Registry governance

MOTU material may inform LENS only when explicitly extracted, neutralized, or
adopted into LENS authority files.

## Relationship To Crucible Registry

This project is organized by the Crucible Registry.

The Registry may describe LENS identity, authority location, relationships,
inherited standards, and boundaries.

The Registry does not own LENS mechanics, doctrine, tests, modules, settings, or
implementation substance.

The 2026-09-17 core adoption of lasting Character Aspects is recorded in
`docs/design/lens-character-aspects-working-package-v0.1.md`. Selection is
optional; one applicable Aspect supplies an independent factor and develops
through play. Baseline, Markdown terminology, and construction references are
updated without changing prices, awards, or existing character records.
Temporary enhancement and other expressly deferred extensions remain unadopted.

The Benefits and Drawbacks framework was also adopted as working core rules
on 2026-09-17, in `docs/design/lens-benefits-and-drawbacks-working-package-v0.1.md`.

remains 125. Actual credit supports existing buyoff logic. Catalogue values
remain provisional, and HOLD/species balancing stays deferred.
