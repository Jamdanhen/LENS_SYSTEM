Date: 2026-09-06
Status: Construction walkthrough using working references; not a new character

## Question and Controls

Can a player finish starting possessions and established position without
inventing construction rules during selection?

Use one ordinary grounded-fantasy example, Rowan, a local caravan escort who
also takes gate duty. Assets, Network, Authority, Reputation, and Background
are each Rank 1. These are supplied inputs for this bounded package test,
not a new complete 25/50/100 build or a conversion of the saved modern guide.
Applicable ordinary training and Profile permission are assumed; no free
Training, HOLT, or extraordinary Access is awarded by the package.

Use the Profile reference B = 200 and the current additional-means formula
B x 5 x Assets Rank: 1,000 additional means, separate from the free package.
Values frame affordability rather than require coin-by-coin shopping.

## Result

Qualified pass for ordinary starting possessions and four Leverage provisions
using the current provisional Profile references. The character has usable,
bounded possessions and relationships without price research, starting rolls,
monthly upkeep checks, or new subsystem rules.

Not a complete pass for the entire established-position package: Background
Rank's starting provisions remain unresolved. The player can record history,
but the designer cannot claim that this completes its mechanical allocation.

Separate presentation need: the Profile must show its equipment choices and
functions together. Existing provisional values support testing, but cannot be
silently promoted to final universal armor or shield rules.
